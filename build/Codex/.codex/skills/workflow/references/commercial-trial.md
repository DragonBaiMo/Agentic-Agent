# 回杯站：多材料提案与一次局部改价

用于理解商业材料入口、指定图片保护和本流程源工程的局部修订。所有企业、数据和承诺均为合成测试情境；不得作为真实产品能力、报价或设计模板移植到其他任务。

## 材料先于版式

输入共8份：历史PPTX、Word报价草案、产品确认稿、会议纪要、需求Markdown、六日台架CSV、产品PNG和茶水间PNG。历史PPT把试点写成两周覆盖全楼，承诺自动清洗、零运维和节约成本，还写了开始日期及设备可留用；产品确认稿与其他材料不支持这些说法。报价草案的日期较新，但仍待负责人确认，不能自行选价。

第一轮问题聚焦演示用途、改动权限和商务冲突。模拟客户确认：向行政与采购负责人讲10分钟，总共5页；旧PPT只作历史参考；四周、一个点位、两台设备；4800元人民币含税，含安装和一次操作培训，不含每日人工收取、清洗与耗材；开始日期待定，结束回收设备。由此形成内容结构，而不是沿旧页润色错误承诺。

CSV合计投入600杯、回收480杯。页面保留“内部台架记录”的场景，不把二者比例宣传为客户使用率，不推出减碳或节约成本。报价答复只解决本次金额与范围，不自动生成付款条款。

## 图片设计与原生对象各负其责

模型先设计封面及证据代表页，再设计其余完整页面；抽取干净背景和青金回环装饰。全部标题、正文、价格及页码用实际可用字体重建为原生文字，数据使用原生图表。两张指定照片没有送模型重绘，在预留槽中按原比例完整插入。

正式PPTX的media字节与两份原PNG的SHA-256一致；图片在实际页面上的引用、比例和完整性另行查看。原图中的黄色斜纹、双投入口和杯子均可见。图片身份核对不代替授权判断，也不等于支持任意输入格式或复杂蒙版。

代表页发现单位“杯”与轴刻度过近，调整文本位置后在完整稿回读中确认。正文、价格和图表保持可编辑；在诊断副本里移动图片、改正文、改图表数值，保存重开验证。正式稿保留工作簿快照，诊断副本不代替正式交付。

## 4800改5200：改的是业务值

第二阶段请求只把含税报价改为5200，其余内容、布局和材料不变。另存数据与deck版本，修改价格及对应备注；不调用图片模型，不覆盖旧交付。

此次观察到：前4页渲染PNG逐字节一致；所有media和图表XML字节相同；图表工作簿解包内容相同；编译后的页面对象只改变报价及相关备注。PPTX的关系ID和ZIP元数据在重新组装后变化，因此没有宣称整个ZIP只有一个字节区间不同。这些是本次结果，不是给未来所有局部修改增加逐字节门槛。

在PowerPoint里直接改图表数据时，独立的大数字、备注或图片文字不会因此自动同步。源工程的单源绑定保障重建时一致，不是目标应用中的自动联动功能。

检查涵盖结构、真实PPTX回读、对象修改保存重开，以及LibreOffice导出PDF的查看；没有操作PowerPoint或Google Slides目标应用。字体未嵌入或分发，高级WordArt/路径文字/特殊字体效果未验证。
