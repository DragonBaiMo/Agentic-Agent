# 能力边界

本包确实写出 PSD 像素层、简单 native type 层、图层组、可见性、图层透明度和四种混合模式。当前为 RGB、8 bit；不是 CMYK 印刷分色流程。

## 三种文字策略

1. 图片形态艺术字：由图像模型生成独立透明图像，可移动/缩放/隐藏，修改文案要重做该素材
2. 原生简单文字：本包写入 Type 数据和缓存像素，支持简单横向单行 CJK/Latin。字号、位置和内容可交给支持该格式的编辑器修改，但目标应用里的字体重排需要实测
3. 混合：按实际造型与当前Type能力逐文字对象选择，同组可以混合艺术图与原生说明。普通字在已支持能力内保持原生，不按标题/正文或固定/常改决定载体。不要为了方便写代码把特殊艺术造型改成普通字体，也不要把信息文字全部栅格化后仍宣称可改字

没有完整的字体塑形、段落排版、竖排、弯曲文字、路径文字和可编辑的复杂艺术效果。部分明显需塑形的字符在入口拒绝；并非对所有语言的完整检测器。字体文件存在/注册成功不等于每个字形覆盖和 PostScript 名称已验证；看图检查缺字，字体身份由配置者核实。多行按行分层可用，但不是可流动的文本框。

## 透明不等于蒙版

图片 Alpha 可保存玻璃、柔光和投影；这是像素层透明度，不是独立可编辑 Layer Mask。没有实现真实矢量形状、剪贴蒙版、智能对象、可编辑渐变/调整层、图层样式或复杂嵌套组。需要这些时选择实际支持的后端并验证，不加几个配置字段冒充已经实现。

物体外透明的 cutout 不代表内部是背景自适应的玻璃。实际素材可能保留原背景折射颜色；Alpha 分布有助于发现但不能自动鉴定材质。交付中分别说明轮廓外透明、内部半透明和烘焙折射，用户需要换背景时应明确取舍。

缩放、Canvas 预乘 Alpha 与 8 bit 存储可能带来微小边缘差异；需要实际看图，不声称原始 RGBA 字节完全一致。本包不会故意阈值化删除弱 Alpha。

语义分层不是恢复原作者源文件。新生成的隐藏区域是合理重建，可能与实际物体不同。源图已合并的反射、阴影或精密图形无法保证完全逆向。

## 验证的三层含义

- 自动技术通过：两个解析器能读图层，结构/字面文字等符合配置
- 视觉检查通过：执行者真正看过基准和重建，按用途认为已足够好，并记录实质残差
- 应用编辑通过：在实际目标应用里打开、修改、保存和再打开都测过

前一项不能替代后一项。本次发布没有真实 Photoshop 桌面测试，没有重新调用图片模型验证新版提示词成功率。文件能解析也不表示未来字体替换没有警告。

## 官方资料

- [ag-psd](https://github.com/Agamnentzar/ag-psd)：PSD 库及支持范围；文字写入能力并不包括自动渲染全部 Photoshop 排版
- [psd-tools](https://psd-tools.readthedocs.io/en/latest/)：独立解析和合成，不负责字体渲染/直接修改文字内容
- [Adobe PSD 文件格式](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)：图层、通道、蒙版与合并预览的不同数据部分
- [Adobe UXP TextItem](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/classes/textitem)：实际 Photoshop 原生文字接口；存在文档不代表当前宿主已连接 Photoshop

这些链接是能力资料，不是新增工具授权或本包已连接服务的证明。
