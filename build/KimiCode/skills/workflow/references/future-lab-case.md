# 真实案例：《未来实验室》

此文件保留来源包的实际制作记录，用于理解设计与故障处理。数值属于当时产物，不是 workflow 1.1 的新生图验收；当前流程允许视觉容错，不恢复自动艺术评分门禁。新版验证另见 validation.json。

## 需求与选择

用户要求 PSD、不用模板，结合 image 模型，允许自由发挥。目标是验证“生成不同语义素材，再对齐组装真实图层”能否工作。

主题选择：冷白实验空间里的钴蓝陶瓷／拉丝金属分裂环，与橙色玻璃光核。设计依据：一个材料冲突明确的装置比多个科技装饰更容易被记住；上方留空为准确中文排版，底部放英文名和少量说明。

排版：中文重黑标题与拉丁无衬线辅助文字。强调色仅给短副标题。原母版有右下角碎片，最终去掉，使主体更集中。

## 实际执行顺序

1. 检查工具能力，确认没有可直接任意新建分层 PSD 的 Adobe 接口，不采用 Express 模板
2. 生成1024×1536无字主概念，读取并看图
3. 用主概念作为同一参考，分别生成背景修复、透明环体、透明光核
4. 读取输出通道：背景RGB；环体与光核RGBA，alpha范围0–254，确有透明
5. 发现模型对象尺寸漂移；按实际包围盒重新注册
6. 尝试将母版交给 Adobe，上传返回访问限制；停止这一路径，保持本地组装
7. 用真实字体生成8个原生文字层及匹配位图，与3个图像层组装
8. ag-psd 首次回读结构通过，但 psd-tools 强制重绘只显示背景
9. 找到当前库实际层序与参考文档描述不一致；改为自底向顶重新写入
10. 两次回读、独立重绘、显隐和视觉检查通过，保存PSD、PNG、源素材ZIP

## 实际注册值

| 素材 | alpha >1 包围盒（左上右下） | 最终 destination（左上宽高） |
|---|---|---|
| 环体 | (58,339,990,1197) | (141,394,800,740) |
| 光核 | (286,564,757,1029) | (443,607,264,260) |

三个源素材的画布都是1024×1536。对象位置并未因为提示词要求同画布就自动保持；这正是显式注册不可省略的原因。

## 图层与结果

- 环境组：干净冷白背景与环境投影1层
- 悬浮装置组：透明环体、透明橙色光核2层
- 文字组：眉题、未来、实验室、副标题、FUTURE LAB、说明、底注、署名8层
- 总计3组、11个实际图层；其中8层被两个解析器识别为原生文字
- PSD尺寸1024×1536，RGB 8 bit；主交付约9.8MB
- 独立重绘平均通道误差0.1200436/255
- 关闭环体改变995821个通道值；关闭光核165513；关闭文字组170745

验证报告原始数值保留在 `examples/independent-verification.json`。源PNG、母版及预览在 `assets/future-lab/`。本包样例的结构化配置来自实际交付，并参数化成可复用入口。

## 如实说明的边界

背景光线与投影在一个像素层里，不是独立可调阴影。模型资产是像素图，不是可编辑3D模型或矢量曲面。原生文字需要对应字体；高级文字排版不在脚本已测范围。

Adobe 上传失败，因此不是 Adobe API 创建的 PSD。没有在 Photoshop 桌面实际开档；“双解析器验证通过”与“Photoshop 实机编辑通过”是两件事。

## 这次经验如何变为技能

保留有效流程：母版约束 → 语义资产 → 测量注册 → 精确文字 → PSD组装 → 独立重绘 → 交付。

保留必要检查：透明文件实际通道、背景去主体、层序、文字类型、缓存与真实重绘一致。

不固化偶然选择：不把钴蓝/橙色、3个组、11层、两行中文标题或 Adobe 某次失败变成所有项目的要求。

脚本从固定路径升级为参数化CLI，新增配置校验、依赖锁、覆盖保护、字体检查与测试。原PSD保持原样，SHA-256：592836d0e67a6adbf197087ad1bee8b3658a14d97be69e5efece3e51039387f5。
