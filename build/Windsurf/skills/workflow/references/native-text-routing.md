# PPTX 文字：按来源、编辑频率和艺术角色选择

先服从用户已定的文字表现与编辑职责。默认美观第一，在保持完整设计的前提下尽量可编辑；用户另有硬性要求时处理具体冲突。标题、正文、数字、标签与导航逐角色选择，不按原生比例评分。原生真实渲染能保持同样的气质与层级就保留；当前实现匹配不了时可用独立文字图片，无需证明该字形在PPTX格式中绝对不可能。明显需要定制绘制的字形、材质或透视可直接走语义图片，不制造必败试验。图片不必覆盖所有文字，原生也不能成为默认字体替换艺术排版的理由。

## 标题的来源与表现是两个判断

用户逐字指定标题时保留准确字面；视觉重做不自动授权改标题。主模型获准拟题时，先根据实际受众、页面职责和材料确定题意，再选择平实主题名或有证据的结论。不要为了适配漂亮字形添加无依据的口号。旧PPT仅作内容参考且已授权重构时，其标题也可重拟；不能把所有材料中的标题都当成用户逐字锁定。

随后独立判断固定/常改及native/art。用户指定的标题可以是固定艺术字，也可以是常改原生字；主模型拟定的标题同样有两种路线。它们并非“用户标题原生、AI标题图片”的对应关系。记录方式见deck契约中的title_contracts，不再重复询问已授权事项。

## 每个文字角色只作一次有依据的选择

1. 先在完整构图中定文字角色及其艺术目标，再标出常改数值、日期、正文等期望编辑的范围；不要从默认文本框布局倒推作品
2. 对可能匹配的原生角色核对可用字体、字重、字宽、字号、字距、行距、斜体、基线及后端能力。路线不确定时做一个真实代表样本；明显需要图片设计的角色直接设计完整母图与语义艺术层
3. 真实渲染的气质、层级、轮廓和阅读关系达标，就复用该原生样式。字体名、安装记录或XML字段正确不能替代看图
4. 样本已出现字形回退或明显气质损失，且没有可靠修正依据时，停止反复换字体名，把责任角色改为独立文字图片并说明不能直接改字。正文与导航同样需要匹配，不能只保住大标题；也不要因一个角色失败把全部文字图片化
5. 文字和装饰可分离时采用混合组件。统一导航槽位、正常/活动态与文字角色；能匹配的原生文字直接重设状态，图片角色复用对应素材，不为每页重新生成整条导航

这项判断是已有视觉检查的一部分，不增加逐页审批。未被放宽的全可编辑或指定字体承诺遇到真实冲突时，说明受影响角色和选择；用户已明确美观优先、允许不能改字的，不再为同一取舍重复确认。

## 原生对象也要承载整页设计

先分清本页的视觉任务。产品页可让原图、超大标题和留白形成主次；证据页可让准确图表承担重心；流程页根据真实阶段建立阅读顺序。不把“原生可改字”执行成每页同一套粗体标题加三栏正文，也不为了显得艺术而削弱数据和条件。

对照母图时，除了字体接近程度，还看视觉焦点、尺度差、文字与图像的关系是否保留。若重组后变得保守，定位是尺度/位置问题，还是载体已经损失字形与气质；只修责任角色，不用不断挪框掩盖字体回退，也不重做整套。克制排版可以适合某些用途，但不能据此宣称达到另一份更强艺术性的参考标准。

一次五页合成商业试用采用了原生大标题与价格、图片艺术背景和两张完整指定原图，说明原生文字可以与画面艺术设计共存。它只支持该组字体和当前后端的这次选择，不证明任意字体效果、导航或WordArt都能无损往返；详见[案例及边界](commercial-trial.md)。

## 面包社导航的具体拆法

用户给出的裁图包含“品牌、菜单、体验、落地”，白色纸纹带、麦穗/分隔符、红色活动纸签，以及放大的白色“体验”。粗黑字和粗白字值得优先尝试原生文本。紙纹、撕边与麦穗可以独立复用，固定四个槽位，活动字的放大不能挤走其他章节。

用户研究包已有原生重建与失败对照。当前JS运行时又在原生样例副本实际完成“体验→试用、75→81pt”和活动态切换到“菜单”，严格导出、保存重开、渲染后，四个框未移动、红签到指定槽、原媒体字节不变。它只证明该基础样例在当前渲染器可用；没有PowerPoint/WPS实测。研究的75/40pt、两字标签预算和装饰素材仅属于该样例，不是通用风格、商用授权或默认模板。

生产时由项目自己的主题、角色与编辑范围定义样式。可执行角色引用、单位、完整状态重设和能力记录见[原生样式源](native-style-tokens.md)。研究装饰不能随公开Skill分发。

## 不混淆格式、后端、渲染与字体

- PowerPoint 应用和 OOXML 格式能表达什么
- 当次获准生成/导入库暴露哪些公共字段，实际写入什么
- 渲染器如何显示，编辑和保存重开后是否保留
- 本机和目标使用者实际有哪些字体，授权是否允许分发/嵌入

当前 workflow 的文本入口是 `scripts/pptx_backend/render_objects.mjs`。普通字符串与结构化run使用不同赋值顺序：结构化文字先设默认样式，再赋带局部覆盖的内容，避免整体setter覆盖run字体、字号和颜色；段落局部间距优先。准确契约见[原生样式源](native-style-tokens.md)，不另造一份排版引擎。这不证明支持所有OOXML/WordArt属性；字段仍须查当前Presentations/实际后端文档和实验，不猜 `stroke`、`warp` 等名字。

缺字体要说明替换后的视觉差异；缺后端功能要说明是当前库未提供或往返丢失，不笼统说“PPT做不到”。未经许可不下载、嵌入或分发字体；只有文件内声明字体族，不能称字体已携带。

文件声明正确也不保证每个渲染器一致。商业实测中Noto Serif CJK SC已写入latin/ea并在本机存在，供应soffice入口的PDF显示衬线，Artifact Tool回读PNG却显示近似无衬线。另一次从发行包独立接手的两页实作也遇到该回退：换另一已登记的CJK字体名未解决，随后固定中文角色采用独立图片，价格、日期和联系句保留原生。它证明了这次角色取舍有效，不证明字体回退的根因或所有字体行为。分别保留真实预览并说明编辑边界，不把任一工具渲染称为PowerPoint/WPS通过。

不能为了“全原生”把文字转为轮廓路径后还说可逐字编辑。采用艺术文字图片时记录准确文本、图片化依据、编辑边界和局部替换方式。后端由实际可用工具、权限及经验证能力选定；缺接口时记录具体版本和能力缺口，不虚构支持。原生对照通过且编辑职责匹配后，不再把这些文字送图片模型。
