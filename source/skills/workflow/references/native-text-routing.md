# PPTX 文字：按来源、编辑频率和艺术角色选择

先服从用户已定的文字表现与编辑职责。用户未指定路线时，文字能用当前后端原生实现，并且实际看起来足够美观、符合设计，可直接用原生文字，固定文案也适用。用户已选择固定艺术标题，或完整构图明确需要独特字形与材质时，直接沿图片设计与语义拆层制作，不再要求先证明原生失败。用户要求大部分固定标题采用艺术字时，主标题、分区标题和固定导航均应纳入该方向；常改正文和数据仍保留原生。数量不是配额，按角色说明必要例外。不追求100%像素相同，也不能拿默认系统字体草率替换。

## 标题的来源与表现是两个判断

用户逐字指定标题时保留准确字面；视觉重做不自动授权改标题。主模型获准拟题时，先根据实际受众、页面职责和材料确定题意，再选择平实主题名或有证据的结论。不要为了适配漂亮字形添加无依据的口号。旧PPT仅作内容参考且已授权重构时，其标题也可重拟；不能把所有材料中的标题都当成用户逐字锁定。

随后独立判断固定/常改及native/art。用户指定的标题可以是固定艺术字，也可以是常改原生字；主模型拟定的标题同样有两种路线。它们并非“用户标题原生、AI标题图片”的对应关系。记录方式见deck契约中的title_contracts，不再重复询问已授权事项。

## 每个文字角色只作一次有依据的选择

1. 常改正文、数值、日期和导航名称优先原生，保留直接改字能力
2. 固定标题和标签按已定艺术目标核对可用字体、字重、字宽、字号、字距、行距、斜体、基线及后端能力。原生路线不确定时用一个真实代表样本对照；明显需要定制绘制字形、材质或形变时直接做完整母图与语义艺术层
3. 气质、层级、轮廓和阅读关系足够好，就复用原生样式到同角色，不再逐页重复生图或反复试字
4. 用户已选艺术表达，或独特绘制字形、纹理填充、复杂形变、精细光学效果超出当前可用字体/后端时，把相应文字角色做成语义图片，并说明不能直接改字。艺术标题在整页构图中设计，不能靠孤立换一块字贴补救失衡版式
5. 文字和装饰可分离时采用混合组件：可复用背景/纸签/麦穗素材，加原生文字。切换当前章节只更新原生文字样式和活动装饰的位置/状态，不为每种状态重新生成整条导航

这项判断是已有视觉检查的一部分，不增加用户审批。用户指定全可编辑或指定字体时优先满足；遇实在无法兼顾的视觉取舍才提出具体选择。

## 原生对象也要承载整页设计

先分清本页的视觉任务。产品页可让原图、超大标题和留白形成主次；证据页可让准确图表承担重心；流程页根据真实阶段建立阅读顺序。不把“原生可改字”执行成每页同一套粗体标题加三栏正文，也不为了显得艺术而削弱数据和条件。

对照母图时，除了字体接近程度，还看视觉焦点、尺度差、文字与图像的关系是否保留。若重组后变得保守，先在已批准方向内调整有依据的字号、行宽、位置与素材占比；原生确实做不到的那一个文字角色再走语义图片，不重做整套，也不增加逐页审批。采用克制排版可以是当前商业场景的合理选择，但不能据此宣称达到另一份更强艺术性的参考标准。

一次五页合成商业试用采用了原生大标题与价格、图片艺术背景和两张完整指定原图，说明原生文字可以与画面艺术设计共存。它只支持该组字体和当前后端的这次选择，不证明任意字体效果、导航或WordArt都能无损往返；详见[案例及边界](commercial-trial.md)。

## 面包社导航的具体拆法

用户给出的裁图包含“品牌、菜单、体验、落地”，白色纸纹带、麦穗/分隔符、红色活动纸签，以及放大的白色“体验”。粗黑字和粗白字值得优先尝试原生文本。紙纹、撕边与麦穗可以独立复用，固定四个槽位，活动字的放大不能挤走其他章节。

本版只完成了这张参考图的视觉拆解，没有提交或验收原生重建小样。下一次先做一个导航条对照：用实际可用的合适粗体试“体验”，再改成“菜单”，保存重开，检查字号、字距、槽位、文字是否仍可编辑。这个试验无需再生成完整页面。

## 不混淆三层能力

- PowerPoint 应用和 OOXML 格式能表达什么
- 当次使用的生成/导入/渲染库暴露哪些字段，保存后是否保留
- 本机和目标使用者实际有哪些字体，授权是否允许分发/嵌入

当前 workflow 的文本入口是 `scripts/pptx_backend/render_objects.mjs` 中创建 textbox，再一次性设置 `shape.text.style = item.style`。这只证明一个样式入口存在，不证明它支持所有 OOXML/WordArt 属性。字段必须查当前 Presentations/实际后端的文档和实验，不猜 `stroke`、`warp` 等名字。

缺字体要说明替换后的视觉差异；缺后端功能要说明是当前库未提供或往返丢失，不笼统说“PPT做不到”。未经许可不下载、嵌入或分发字体；只有文件内声明字体族，不能称字体已携带。

文件声明正确也不保证每个渲染器一致。商业实测中Noto Serif CJK SC已写入latin/ea并在本机存在，LibreOffice导出的PDF显示衬线，Artifact Tool回读PNG却显示近似无衬线。分别保留真实预览，编辑说明列实际字体和差异；不把某一渲染器的回退当作已通过目标应用验证，也不因此把应原生的正文偷偷图片化。

不能为了“全原生”把文字转为轮廓路径后还说可逐字编辑。若采用艺术文字图片，记录已选艺术表达、编辑边界和局部替换方式；依据可以是用户选择、完整构图的独特字形或当前原生能力不足，不要求每个角色先经历一次原生失败。原生对照通过且编辑职责匹配后，无需把简单文字继续送图片模型。
