doctor：Python 3.12.14、Node 24.19.0，锁定 Python 包版本一致，@napi-rs/canvas 0.1.100 和 ag-psd 31.0.0 实际加载成功。两份当前字体文件存在；报告明确不自动核实 font identity。

measure_text：Open Sans Condensed Light 的英文展名 advance 352.147998 px、日期 432.064992 px；针对 352/432 px 目标给出 tracking 275.7197/184.9078。实际原配置 276/185 已接近，不改海报。数值是逐字 advance，不是字形墨迹或 Photoshop 重排。

probe：螺壳源图非零 Alpha 574,884 个，其中 Alpha 230–255 为 564,668 个（98.22%）；投影非零 230,442 个，其中 1–229 为 209,711 个。数据说明两种材质 Alpha 分布差异，不能直接算出“玻璃合格”。

## 交互走查与审读

组织人完整审读 SKILL.md 与 interaction-and-layers.md，确认两个节点可合并、推荐分层可理解、叶层/组分开、全自动不伪造批准及轻量容错。作者按包内文件走查：

| 场景 | 应做的决定与可定位路径 |
|---|---|
| 用户只说“做一张海报，交 PSD” | 默认 staged；先实际完整母图，再把母图与推荐架构合并展示，等待选择后大量拆层 |
| 用户说“全自动，你来定” | autonomous，记录实际授权、推荐最小充分层和文字取舍；完成后如实交接 |
| 用户已选母图并指定 8 层和可改字范围 | 不重问已知选择；按约定实施，若数量或可改字承诺需变化才说明并确认 |
| 重做导致玻璃仍烘焙旧背景，而用户要任意换底 | 明确编辑能力缺口；提出取舍，不靠外侧透明或整体降 opacity 声称完成 |
| 同一方向仅平移、换近似窄体并调字距 | 保留快照、局部修改、新构建、实际看图，不逐小步问用户 |

这是文件走查和审读，不是本版又一次无上下文新代理完整生图试用。没有为追求测试形式另加审批系统。
